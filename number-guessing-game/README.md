# 🎯 Number Guessing Game

A simple command-line number guessing game written in Python.

## 📖 Description

The computer generates a random number within a range chosen by the player. Your goal is to guess the number using as few attempts as possible.

## ✨ Features

- Custom number range
- Input validation
- Hints for higher and lower guesses
- Attempt counter
- Option to play again without restarting the program
- Automatic handling of reversed range boundaries

## 🛠️ Requirements

- Python 3.x
- No external libraries required

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/DexarDev/python-mini-projects.git
```

Navigate to the game directory:

```bash
cd python-mini-projects/number-guessing-game
```

Run the program:

```bash
python main.py
```

On Windows, you can also use:

```bash
py main.py
```

On macOS or Linux, if `python` doesn't work, try:

```bash
python3 main.py
```

## 🎮 How to Play

1. Enter the minimum and maximum values on separate lines.
2. Enter your guess.
3. Follow the hints:
   - **Too high** - your guess is greater than the secret number.
   - **Too low** - your guess is smaller than the secret number.
4. Keep guessing until you find the correct number.
5. Choose whether you want to play again.
